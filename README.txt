KREOVA AI MVP v1 (gratis)
File:
- index.html: aplikasi utama (buka langsung untuk uji; instalasi PWA perlu hosting HTTPS)
- manifest.webmanifest: identitas PWA
- icon.svg: ikon
- sw.js: cache offline dasar

Hosting gratis:
1. Buat repo GitHub baru (mis. kreova-ai).
2. Upload semua file dari folder ini ke root repo.
3. Repo Settings > Pages > Deploy from branch > main / root.
4. Tunggu URL GitHub Pages aktif.
5. Buka URL di Chrome Android, menu ⋮ > Add to Home screen / Install app.

Catatan:
Versi ini adalah prompt builder / creative brief offline, bukan model AI generatif yang berjalan langsung.
Project disimpan di localStorage browser/perangkat. Hapus data browser bisa menghapus proyek tersimpan.
